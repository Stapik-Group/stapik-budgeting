# Kategorien

Kategorien gruppieren deine Einträge und geben ihnen eine Farbe. Unter **Bearbeiten → Kategorien…** fügst du sie hinzu, bearbeitest oder löschst sie.

Tippe in das Suchfeld, um eine Kategorie nach Namen zu finden. Ein Doppelklick auf eine Kategorie oder die Eingabetaste öffnet die Bearbeitung.

Das Löschen einer Kategorie löscht ihre Einträge nicht. Sie erscheinen als *Ohne Kategorie*, bis du eine andere zuweist.
