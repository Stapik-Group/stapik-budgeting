# Cloud-Synchronisation

Mit **Datei → Mit Cloud verbinden** hältst du mehrere Geräte über Stapik Cloud auf demselben Stand. Gib die Adresse und den API-Schlüssel ein, optional auch eine Ende-zu-Ende-Passphrase.

Ist die Cloud verbunden, zeigt die untere Leiste den Zustand: aktuell, Synchronisation, offline, Konflikt oder Fehler. Änderungen werden zuerst lokal gespeichert und im Hintergrund gesendet, das Fenster wartet also nie auf das Netzwerk.

> Die neuere der beiden Kopien gewinnt als Ganzes. Synchronisiere, bevor du auf einem anderen Gerät bearbeitest.
