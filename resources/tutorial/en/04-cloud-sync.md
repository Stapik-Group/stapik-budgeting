# Cloud sync

Use **File → Connect to cloud** to keep several devices in step through Stapik Cloud. Enter the address and the API key, and optionally an end-to-end encryption passphrase.

When the cloud is connected, the bottom bar shows the state: up to date, syncing, offline, conflict or error. Changes are saved locally first and sent in the background, so the window never waits for the network.

> The newer of the two copies wins as a whole. Synchronize before you edit on another device.
