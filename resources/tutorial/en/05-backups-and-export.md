# Backups and export

* **File → Restore from backup…** returns to one of the last saves of the budget. The data it replaces becomes the newest backup, so a restore can be taken back.
* **File → Back up the whole application…** writes one ZIP file with the budget and the settings. **Restore the whole application…** reads it back.
* **File → Export month to CSV…** opens in a spreadsheet. **Export month to PDF…** and **Print month…** produce the displayed month as a document.
